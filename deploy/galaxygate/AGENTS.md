# GalaxyGate packaging

The Compose application target is a build configuration for the completed service, not a deployment tested in this delivery. Provision digest-pinned base images, persistence writable by the service UID, HTTPS ingress, actual WorkOS session/Connect configuration, backups and restore checks. Never publish a diagnostic source-tools pass as application readiness. No Cloudflare, hidden Node server, iii daemon, or host credentials are automatically created.

Require the implemented /healthz and readiness semantics before wiring the platform health probe. Verify cookie/CSRF behavior and SSE/MCP streaming through the actual ingress. Conversion native libraries/models must be qualified and included in the image or fetched explicitly with verified checksums before advertising format support.
