# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for it.

## Supported versions

No version has been released, so none is supported yet.

## Security requirements

The product's security requirements (authentication paths, connector credentials, workspace isolation, hostile HTML and secret handling) are in [SPEC.md](SPEC.md), section 11.
