# Qualify real conversion

Read the converter vendor entry and the pinned library sources. Record the native libraries and model assets the pinned Docling release actually requires, with their verified download locations, versions, hashes and configured local paths; never invent a hash. Exercise text PDF, a scanned PDF, DOCX with images, and a sheet range; preserve original and locators. Capture conversion settings/native assets and errors. Run cancellation and resource bounds. No successful empty digest for unsupported content; retained bytes with an unsupported or failed extraction state is a fallback, not qualification. Qualification is unexecuted.

```sh
bun scripts/dev.mjs vendor docling
```
