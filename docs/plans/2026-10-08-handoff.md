## Rules that bind (beyond AGENTS.md)
- Merge commits only; never rebase, squash, amend a pushed commit or force-push. Commit at every green step: subject `type(scope): what.`, body `Why:`, `What changed:`, `Verified:`, `Next:`/`Blocked:`, trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. PR bodies end with `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
- No Python in product or tooling (the one exception: `.github/workflows/contract.yml` runs schemathesis, confined to CI).
- Never post upstream issues, PRs or comments; the owner posts. Never put a personal e-mail address or a machine path in a tracked file; receipts are scrubbed by `scripts/lib/provenance.mjs`.
- Nobody types a gate status: `bun qualification/record.mjs <gate>` after a real run on a clean commit; `bun scripts/dev.mjs check-receipts` must agree. Any change to a receipt input (Cargo.lock; ui/src; api/ and generated files the App reads; view fixtures) makes that receipt stale: requalify, never exempt.
- Independent review for every package; a finding blocks only with a failing command or a named SPEC/AGENTS/brief sentence; at most two review rounds. No new framework, registry or generator layer; build product behaviour.
- Sub-agent messages are not owner approval. Product-taste questions go to the owner; engineering calls are made and recorded.

Peak memory is about 2.2 GB for the 18-page PDF with page images on.
